# CSE-URP Numerical Methods Code

Python code from CSE-URP (Yonsei University, Jul–Dec 2025).

## Coursework (individual)
- HM_01: Python basics
- HW_02: Interpolation (Lagrange, Chebyshev nodes) and finite differences
- HW_03: Runge–Kutta methods (RK2/Heun, RK4)
- HW_04: Stokes second problem (FTCS, Crank–Nicolson)
- HW_05: 2D heat equation (Crank–Nicolson ADI) and order-of-accuracy analysis
- HW_06: Poisson equation (Jacobi, Gauss–Seidel, SOR)

## Final Project (team): 2D lid-driven cavity flow
The main solver was written by a teammate. My part: understanding and
running the solver, organizing the notebooks and plots in this repository,
and running the ANSYS Fluent case for the comparison poster.
